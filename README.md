# GEN Shortage Control Panel

A single-page, offline-capable web tool for generator (GEN) shortage planning.

**Open the app:** see the GitHub Pages link in this repository's About section.

## How it works
1. Open the page and click **Import data**.
2. Drop in your Excel exports: All Orders Report (required), genforecast, TAD Report and Gen Swap Summary.
3. The panel shows which orders are short of a GEN, compatible substitute GENs, open swap loops and
   an explainable delay-risk score. Click cards, bars and rows to drill down; tag orders and export.

## Privacy
This repository contains **no data**. The page is a static HTML file. Excel files you import are read
and processed entirely inside your browser and are never uploaded or sent anywhere. Tags and notes are
stored only in your own browser.
